# Southern Illinois Regional AI Hub

Project website for the proposed Southern Illinois Regional AI Hub, hosted by the School of Computing at Southern Illinois University Carbondale.

The hub would combine shared GPU infrastructure with ready-to-use learning and research environments, guided activities, and technical and instructional support for SIU, K–12 schools, community colleges, and community partners across southern Illinois.

- **Website:** `index.html` (a single static page, no build step)
- **Full proposal:** [`assets/SIU-Regional-AI-Hub-Proposal.pdf`](assets/SIU-Regional-AI-Hub-Proposal.pdf)

## Publishing with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the **main** branch and the **/ (root)** folder, then click **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.
